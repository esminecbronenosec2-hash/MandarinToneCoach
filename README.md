# Mandarin Tone Coach — Android

Русскоязычный учебный Android-прототип: пять тонов, слова, фразы, китайский TTS, микрофон, локальный F0-контур, викторина и статистика.

## Сборка APK без компьютера через GitHub Actions

1. Создайте **пустой** GitHub-репозиторий (например `MandarinToneCoach`). Можно выбрать **Private**.
2. Распакуйте `MandarinToneCoach-GitHub-ready.zip` на телефоне. В репозиторий надо загрузить **содержимое папки `MandarinToneCoach`**, не сам ZIP и не внешнюю папку.
3. В браузере GitHub откройте репозиторий → **Add file → Upload files**. Для сохранения вложенных папок удобнее выбрать папку через файловый менеджер/режим рабочего стола браузера. **Проверьте, что `.github/workflows/build-apk.yml` действительно загружен**. На некоторых мобильных браузерах загрузка папок не поддерживается; тогда воспользуйтесь GitHub веб-редактором (`.` на странице репозитория) или Git-клиентом на Android.
4. Commit changes в ветку `main` (либо `master`).
5. Перейдите в **Actions → Build Android APK → Run workflow** (или дождитесь автоматического запуска после push).
6. Дождитесь зелёного результата → откройте запуск → **Artifacts → MandarinToneCoach-debug-apk**. GitHub скачает ZIP с `app-debug.apk` внутри.
7. Распакуйте скачанный ZIP, нажмите `app-debug.apk` на Samsung Fold5 и подтвердите установку из этого источника, если Android спросит.

Workflow: `.github/workflows/build-apk.yml`. Собирает **debug APK** с тестовой подписью. Google Play не требуется. Артефакт доступен 14 дней; для загрузки из приватного репозитория потребуется вход в GitHub.

## Локальная сборка

JDK 17, Android SDK API 35, Gradle 8.9:

```sh
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Ограничения

- Сборка через GitHub Actions **ещё не запускалась**, работа APK на Fold5 пока не проверена.
- Это **прототип**, не завершённая система распознавания речи. Сходство вычисляется по контуру F0; звуки и слова не распознаются.
- Для многосложных фраз сейчас оценивается только один целевой тон; нет послоговой сегментации и учёта сандхи.
- TTS требует установленного китайского голоса на телефоне. Нейтральный тон оценивается условно.
- Аудио остаётся на устройстве; статистика хранится локально.
