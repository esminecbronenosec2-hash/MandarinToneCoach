# Third-party components

- **Vosk Android 0.3.75** — [alphacep/vosk-api](https://github.com/alphacep/vosk-api), Apache 2.0.
- **vosk-model-small-cn-0.22** — [Vosk model catalog](https://alphacephei.com/vosk/models), Apache 2.0. Downloaded for each GitHub Actions APK build from its publisher to package with the app. This is an open-source on-device Mandarin speech recognition model. The model ZIP is not committed to Git and is not included in the small source ZIP.
- **Pinyin4j 2.5.1** — [belerweb/pinyin4j](https://github.com/belerweb/pinyin4j), BSD. Maps Chinese ideographs to possible syllable readings, but does not resolve all multiple-reading ambiguities.
- **Java Native Access 5.18.1 (Android AAR)** — [JNA](https://github.com/java-native-access/jna), LGPL-2.1 or Apache 2.0 dual licensing.

Application source code is MIT licensed and is separate from the upstream models and libraries. These third-party components are redistributed only according to their own licenses and published model terms.
